# Off-Guard

- This is a Hurtful Condition.
- This is a Binary Condition. It is either active or not.
- This can be a Situational Condition.

Off-Guard lowers Armor temporarily.

## Situational

A Squaddie can be Off-Guard in certain situations.
The condition can also be applied normally.

### Flanking

The most common situational Off-Guard scenario involves a Squaddie with unfriendly Squaddies surrounding them on
opposite corners (left-right, upleft-downright, upright-downleft.) Only these flanking unfriendly Squaddies treat the
Squaddie as Off-Guard. Another unfriendly Squaddie would need a flanking partner.

### Don't Stack

An action could inflict the Off-Guard condition as normal, like a blinding powder making the Squaddie Off-Guard to all
attacks. A flank doesn't do anything in that case because the Squaddie is already Off-Guard.
