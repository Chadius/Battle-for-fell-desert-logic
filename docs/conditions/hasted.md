# Hasted

- This is a Helpful Condition.
- This is a Binary Condition. It is either active or not.

Hasted gives the Squaddie a single bonus action point at the start of their turn. This action point can only be used
with a single action point action or with movement.

If the squaddie uses a different action, their normal action points are spent first. This is designed to prevent
Squaddies from performing 2 2-action point actions per turn, as the game's balancing factors rely on 1 big ability or
several small ones per round. These Squaddies can use Reactions.

## Interaction with Slowed

If a Squaddie is Hasted and Slowed at the same time, they cancel each other out with no net effect on action points.

# Ways to use Hasted action points

The Bonus Action point granted through Hasted will be used as the first legal action that costs a single Action Point.
Alternatively it can be combined with a movement action that has variable cost.

### Valid Example: Move 4 times

A Squaddie can spend an action point to move 2 distance. While Hasted, They can move up to 8 distance away. Without
Hasted they would only move 6 tiles.

Default Movement has a variable action cost, so Hasted can apply here.

If the squaddie only wanted to move 2 distance, this would first consume their bonus action point. This way they can use
3 action point abilities.

### Valid Example: Basic Attack

A Squaddie can spend the bonus action point to swing a longsword, provided the Longsword Action costs 1 point.

The squaddie can use the Longsword Action up to 4 times (bonus action + 3 standard actions) this turn if they wish. The
Multiple Attack Penalty will make their third and final attack have the largest penalty (of -6.)

### Invalid Example: Two Lightning Bolts

The Lightning Bolt is a 2-action spell. A Squaddie without Haste only has 3 action points so they can only use it once
per turn.

With haste, they are still limited to one Lightning Bolt. Lightning Bolt cannot consume the bonus action point because
it costs 2 action points. So the first casting leaves the bonus action point and 1 more action point.
Lightning Bolt cannot use the bonus action point, so the Squaddie only has 1 more point. That's not enough.
