# Slowed

- This is a Hurtful Condition.

Slowed removes action points from the Squaddie, according to its amount. Slowed has a duration.

Slowed squaddies cannot use Reactions.

## Interaction with Hasted

If a Squaddie is Hasted and Slowed at the same time, they cancel each other out with no net effect on action points.
These Squaddies can use Reactions.
